# 🧪 Almosafer Automation Testing Project

This is an automated test suite developed in **Java** using **Selenium WebDriver** and **TestNG** to test the functionality of the [Almosafer](https://www.almosafer.com/) travel booking website.

---

## 📋 Project Overview

This project aims to validate key UI components and workflows on Almosafer’s website, including:

- Default language and currency
- Contact number visibility
- Hotel tab functionality
- Date selection logic
- Randomized input tests
- Search results validation

---

## 🚀 Tech Stack

| Tool/Library     | Purpose                     |
|------------------|-----------------------------|
| Java             | Main programming language   |
| Selenium WebDriver | Browser automation       |
| TestNG           | Test framework              |
| ChromeDriver     | Chrome browser automation   |
| Maven (optional) | Dependency management       |

---


---

## ✅ Test Coverage

* Language check (Arabic/English)
* Currency default (SAR)
* Contact support number
* Hotel tab and city input
* Departure/return date logic
* Dynamic language & city selection
* Search result page verification

---

## 📌 Notes

* Tests use randomized city selection from a predefined list.
* Date calculations are dynamic based on the system date.
* Timeout and waits should be improved using `WebDriverWait` instead of `Thread.sleep()` in future versions.
